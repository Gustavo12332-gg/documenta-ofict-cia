## Descrição do Projeto
O projeto de implementação de ferramentas foi dividido em 3 etapas, cada uma com seus objetivos especi­ficos. A seguir, serão descritas as etapas do projeto:

Etapa 1:

- [banco de dados]
- [ O DynamoDB é provavelmente o banco ideal para catálogo farmacêutico porque lida bem com esquemas flexíveis (cada medicamento pode ter atributos diferentes), escala automática e consultas de alta velocidade]

Etapa 2: 
- [Amazon QLDB]
- [O Amazon API Gateway é um serviço totalmente gerenciado da AWS que permite criar, publicar, monitorar e proteger APIs RESTful, HTTP e WebSocket em qualquer escala. Ele funciona como uma "porta de entrada" para que aplicações acessem dados, lógica de negócios ou funcionalidades de serviços de backend]
- [Integração Direta com ERP e Cadeia de Suprimentos
Em vez de trocar e-mails ou planilhas, seus parceiros industriais podem consultar diretamente seus sistemas via API.

Consulta de Inventário em Tempo Real: Parceiros podem verificar a disponibilidade de lotes específicos de insumos ou produtos acabados.

Automação de Pedidos: O sistema de compras da indústria compradora "conversa" com o seu API Gateway, gerando ordens de venda instantâneas.]

Etapa 3: 
- [ Amazon Location Service]
- [O Amazon Location Service é um serviço de mapeamento que permite adicionar funcionalidade de localização às aplicações, incluindo mapas dinâmicos e estáticos, pesquisa de locais e geocodificação, planejamento de rotas e recursos de rastreamento de dispositivos e cerca geográfica]
- [O Amazon Location Service complementa o API Gateway ao adicionar inteligência geográfica à sua logística de distribuição. Em uma indústria farmacêutica, onde o tempo de entrega e a integridade da carga (controle de temperatura e manuseio) são críticos, esse serviço resolve desafios de visibilidade e eficiência.

Aqui estão as principais formas de utilizá-lo:

1. Rastreamento em Tempo Real (Asset Tracking)
Diferente de apenas saber que um produto saiu do galpão, o Location Service permite monitorar a posição exata da frota.

Histórico de Dispositivos: Você pode armazenar o histórico de posições para auditorias de conformidade, comprovando o trajeto feito por um lote de medicamentos.

Gestão de Custos: Ao usar o serviço da AWS, você paga apenas pelo que usa, o que costuma ser mais barato do que licenças fechadas de frotas para grandes volumes de dados geográficos.]
